The Canvas API & Coordinates

In standard web design, we use HTML elements like <div> and CSS rules to build grids. But if you want to build a promotional game with 500 asteroids flying across the screen, creating 500 HTML div elements will cause the user's browser to crash. The DOM is simply too heavy for that much movement.

Instead, we use the HTML5 <canvas> tag. Which HTML element is designed for high-performance drawing via scripting? <canvas>. The canvas is literally just a blank digital painting frame. We use JavaScript to grab a set of "digital paintbrushes" and manually paint our graphics directly onto it.

The 2D Context (ctx)

To start painting, we need the tools. Which method is used to get the 2D drawing context for a canvas element? getContext('2d'). We usually store this in a variable named ctx.

The Coordinate System (Not Like Math Class!)

In your geometry class, the origin point (0,0) is in the center, and Y goes UP. A computer screen works differently.

  • Which coordinate represents the top-left corner of the canvas? (0, 0).
  • If you want to move an object to the right, what must you do to its X coordinate? Add a positive value to X. (X increases left to right).
  • If you increase an object's "Y" coordinate value, which way does it move on the screen? It moves DOWN! Y increases from the top to the bottom. If you want a bullet to travel upwards, what should its Y-velocity be? A negative number.
Why is (0,0) in the top-left? A screen draws its picture the way you read a page: it starts at the top-left corner and fills in row by row, moving down the screen. The computer counts from where it starts drawing, so the top-left is (0,0). Because Y grows downward, the canvas has an inverted Y-axis (flipped upside down compared to math class). That changes your math: adding to Y moves an object down, and subtracting from Y moves it up. A jump is a negative change in Y.
Drawing Shapes & Images

Once we have ctx, we can draw. Which JavaScript method is used to draw a solid, colored rectangle? fillRect(x, y, width, height).

But what if we want it to be red? Which Canvas property is used to set the color of a shape before it is drawn? ctx.fillStyle = "red";.

Method/PropertyWhat it Does
ctx.beginPath()Which method is used to start a path for drawing custom shapes? This one. It resets the pen.
ctx.arc()Draws circles/curves. When using ctx.arc(), which parameter defines the size of the circle? The radius.
ctx.lineWidthWhat property determines the thickness of lines drawn with stroke()? ctx.lineWidth.
ctx.fillText()How do you draw text on the canvas? Use ctx.fillText("Score: " + score, x, y).
ctx.drawImage()Which Canvas API method is used to render an image asset (like a character sprite) onto the screen? ctx.drawImage().
beginPath() + fillStyle + arc() — Used Together

You must always use beginPath() before drawing a shape, and set fillStyle before calling fill(). Without beginPath(), the canvas re-draws old paths on top of new ones.

// Drawing a filled green circle (asteroid)
ctx.beginPath();                    // 1. Reset the pen path
ctx.arc(x, y, radius, 0, Math.PI * 2); // 2. Define the circle shape
ctx.fillStyle = "#22c55e";         // 3. Set the fill color
ctx.fill();                        // 4. Fill the shape
ctx.closePath();                   // 5. Close the path

// Drawing a colored rectangle (player)
ctx.fillStyle = "royalblue";       // Set color FIRST
ctx.fillRect(playerX, playerY, 40, 40); // Then draw
// Note: fillRect does NOT need beginPath()

Animation & The Game Loop

How does a flipbook work? You draw an image, turn to a blank white page, and draw the image shifted slightly. Computer animation is the exact same. We must completely wipe the canvas clean before drawing the next frame.

The Pro Engine: requestAnimationFrame

Which method tells the browser to perform an animation and requests a call to a function to update before the next repaint? requestAnimationFrame(). Why is requestAnimationFrame better than setInterval for games? Because it syncs with the monitor's refresh rate (for smooth 60fps motion) and automatically pauses when the user switches tabs, saving battery life. This is critical for meeting our agency's WRS Reliability standards.

Most monitors refresh 60 times per second (60Hz). requestAnimationFrame() lines up each new frame with the monitor's refresh to prevent screen tearing: a glitch where the screen shows the top part of one frame and the bottom part of the next at the same time, so the picture looks sliced across the middle. Drawing in step with the monitor also avoids the stutter you get when frames arrive at the wrong moment.

How do you stop a game loop when the player loses? You use cancelAnimationFrame().

The 3 Steps of a Game Loop

When setting up a game loop, in what order should the core functions generally execute? Clear canvas -> Update logic -> Draw objects. This happens 60 times a second.

  • 1. Clear: How can you completely clear the entire canvas element ctx? You use ctx.clearRect(0, 0, canvas.width, canvas.height). What happens if you don't call clearRect() or fillRect() at the start of every frame? The previous frames' drawings will stay on the screen, creating an ugly smearing effect!
  • 2. Update: The "Update" portion of the game loop is responsible for calculating new positions and checking collisions. (e.g. player.x += speed;).
  • 3. Draw: Finally, you render the new graphics.

Walkthrough: The Game Loop 

let playerX = 50;
let speed = 5;

function gameLoop() {
    // 1. CLEAR
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    // 2. UPDATE
    playerX += speed; // Move right
    
    // 3. DRAW
    ctx.fillStyle = "blue";
    ctx.fillRect(playerX, 50, 40, 40);
    
    // LOOP
    requestAnimationFrame(gameLoop);
}
gameLoop(); // Start the engine
Going Further: Bounce Off All Four Edges

The walkthrough only moves the box to the right. To keep an object bouncing around inside the canvas, give it a speed on both axes and check all four edges every frame. When it hits the left or right edge, flip its X direction. When it hits the top or bottom edge, flip its Y direction. Multiplying a speed by -1 reverses it.

let x = 50, y = 50, size = 40;
let speedX = 4, speedY = 3;

// Inside the UPDATE step of your game loop:
x += speedX;
y += speedY;
// Left or right edge? Reverse the X direction.
if (x <= 0 || x + size >= canvas.width)  { speedX *= -1; }
// Top or bottom edge? Reverse the Y direction.
if (y <= 0 || y + size >= canvas.height) { speedY *= -1; }

Why x + size? A box's x and y are its top-left corner. Its right edge is at x + size and its bottom edge is at y + size, so those are what you compare to the canvas width and height.

OOP & Classes (The Blueprint)

If you are building a game with 50 aliens, it would be a nightmare to create 50 `alienX` and 50 `alienY` variables. This is "Spaghetti Code," and it wastes our agency's billable hours. Instead, we use Object-Oriented Programming (OOP).

What is the name of the "Blueprint" used in Object-Oriented Programming to create multiple objects? A Class. What is the main advantage of using a Class to build game objects? It encapsulates properties and methods for reuse. You write the code once, and you can spawn a thousand enemies perfectly.

Key Terms: The Blueprint and Its Copies
  • Spaghetti Code: messy, repetitive code that is tangled together and hard to follow, like enemy1_x, enemy2_x, enemy3_x... Every new enemy means copying more variables, and one fix has to be made in fifty places.
  • class: the keyword that creates a modular, reusable "Blueprint," like class Enemy { }.
  • constructor: the "birth" of the object. It runs once, at the moment a new object is created, and gives that object its starting values: where it starts, how fast it moves, and how much health it has.
  • new: the keyword used to instantiate (create) copies from a class: new Enemy().
  • Class vs. instance: a class is the blueprint; an instance is one object built from it. Enemy is the class; const enemy1 = new Enemy(); makes an instance. Fifty enemies on screen means one class and fifty instances.
  • Capitalized class names: class names start with a capital letter, as in class Enemy, so you can tell a blueprint (Enemy) from an instance (enemy1) at a glance.
Anatomy of a Class
  • Naming: What naming convention is the industry standard for Class names? Capitalized (PascalCase), like `class Enemy`.
  • Constructor: In JavaScript ES6, what function runs automatically when a new instance of a class is created? The constructor(). This is where you set the starting X/Y coordinates.
  • Context (this): In a class, what does the 'this' keyword refer to? The specific instance of the object being created/updated. If you forget to include `this.` before a variable inside a class method, what happens? The computer looks for a global variable instead, causing a Reference Error. Which property of a class instance allows it to 'know' how much health it has left? A property defined in the constructor, like this.health.
  • Methods: How do you define a new method inside a JavaScript class? You just write MethodName() { } without using the word `function`.
Instantiating & Arrays

How do you create a brand new enemy from an Enemy class? You use the `new` keyword: new Enemy(). When spawning many, we store them in an array.

  • Which array method is best for adding a newly spawned projectile to a list of active bullets? bullets.push().
  • If you have an array of asteroids, how do you remove the first one from the array after it is destroyed? You use asteroids.shift().
  • If you use asteroids.filter(a => !a.destroyed), what are you doing? You are creating a new array containing only asteroids that are NOT destroyed. This is how we clean up memory!

Physics, Collisions, & User Input

How does a video game actually 'know' when a bullet hits a monster? A "Hitbox" is used in game logic to determine if two objects are overlapping or touching. What is a 'Hitbox'? It is The invisible area used to calculate collisions, which is often smaller than the actual graphic being drawn.

AABB Collision (Rectangles)

AABB Collision detection stands for Axis-Aligned Bounding Box. It requires checking the overlap of which properties? x, y, width, and height. Which operator allows us to check multiple collision conditions at the same time? We MUST use the && (AND) operator, because all four sides must overlap simultaneously for a true hit.

// The Pro AABB Formula
if (rect1.x < rect2.x + rect2.width &&
    rect1.x + rect1.width > rect2.x &&
    rect1.y < rect2.y + rect2.height &&
    rect1.y + rect1.height > rect2.y) {
    // Collision detected!
}
The rule in plain English: two rectangles are touching when their edges overlap on both the x-axis and the y-axis. Overlapping on just one axis is not a hit. Two boxes at the same height on opposite sides of the screen overlap on y, but not on x, so they are not touching.

Reading the x-axis half: a.x < b.x + b.width && a.x + a.width > b.x means "a's left edge is to the left of b's right edge, and a's right edge is to the right of b's left edge." The y-axis half asks the same question about the top and bottom edges.

Circular Collision

For circular hitboxes, we don't use X and Width. To check for circular collision, which mathematical theorem is typically applied to find the distance between center points? The Pythagorean theorem ($a^2+b^2=c^2$). In circular collision detection, when has a collision occurred? When the distance between centers is less than the sum of the radii.

Physics Math
  • Canvas Boundaries: To prevent an object named player from moving off the left edge of the canvas, which condition should you check? if (player.x < 0). If player.y + player.height >= canvas.height evaluates to true, what is happening? The player is touching the bottom of the canvas.
  • Bouncing: How do you make an object 'bounce' off the bottom of the canvas? You reverse its direction: velocity.y *= -1.
  • Screen Wrapping: How do you create an 'infinite' wrap-around effect on the X-axis? if (x > width) x = 0.
  • Speed: To make an object move faster, you should Increase the value added to its position per frame.
  • Gravity: To apply basic gravity to a jumping character, what must you do every frame? Add a constant value to the character's vertical velocity. Simulating gravity usually involves adding a small value to an object's Y-velocity.
  • Friction: What is 'Friction' in game physics? Gradually reducing velocity over time (e.g. `speed *= 0.98`).
Keyboard & Mouse Inputs

Which event listener is typically used for continuous character movement in games? The keydown event. How do you detect if a user has released a key to stop moving? Listen for the 'keyup' event.

What property of a keyboard event tells you the physical key that was pressed? event.code (e.g. 'ArrowRight' or 'Space'). How do you check if a specific key (like 'Space') is currently being held down? Store the key state in a boolean variable inside keydown/keyup listeners.

Which event listener is used to track the mouse position on the canvas? 'mousemove'.

State Management

What is the purpose of a 'Game State' variable (like gameState = 'menu')? To control which screens or logic blocks are active. A Game State variable is used to control which logic runs at different times.

When building a Start Screen, how do you prevent the main game loop from running until a button is clicked? Wrap requestAnimationFrame inside a conditional state check (e.g. if(gameState === 'playing') requestAnimationFrame(loop);).

Game State Pattern — switch/case

Define a state variable that can hold exactly one of your named states at any time. Your game loop reads it and executes only the matching block.

// Define possible states: "start", "playing", "paused", "gameover"
let gameState = "start";

function gameLoop() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    switch (gameState) {
        case "start":
            drawStartScreen();  // Show title + "Press Space to Play"
            break;

        case "playing":
            updateEntities();   // Move players, enemies, bullets
            checkCollisions();  // AABB checks
            drawAll();          // Render everything
            break;

        case "paused":
            drawAll();          // Keep drawing the frozen scene
            drawPauseOverlay(); // Dim + show "PAUSED" text
            break;

        case "gameover":
            drawGameOverScreen(); // Score, "Play Again" button
            break;
    }

    requestAnimationFrame(gameLoop);
}

// Change state when player presses Space
document.addEventListener("keydown", function(e) {
    if (e.code === "Space" && gameState === "start") {
        gameState = "playing";
    }
    if (e.code === "KeyP" && gameState === "playing") {
        gameState = "paused";
    } else if (e.code === "KeyP" && gameState === "paused") {
        gameState = "playing";
    }
});
Map Your State Machine

A game built this way is a state machine: it is always in exactly one state, and only specific events, called transitions, can move it to another state. Before coding, draw each state as a box and every transition as an arrow. If you cannot draw an arrow to a state, the player can never get there.

Validate Your Code: Linting Tools

Why it matters: A game with 500 lines of physics and collision math is exactly the kind of codebase where a single typo — a stray comma, an = instead of ===, a variable you meant to declare but forgot — can silently produce the wrong behavior instead of an obvious crash. The browser console only tells you about errors that actually stop execution; it says nothing about the bugs that just quietly run wrong.

What it is: A linter is an online or editor-integrated validation tool that reads your JavaScript without running it (this is called "static analysis") and flags suspicious patterns before they ever reach a player's browser. The two industry-standard tools are JSHint (jshint.com — paste code, get instant feedback) and ESLint (the professional standard, usually installed as a VS Code extension that underlines problems in real time as you type).

How it works: Before turning in a milestone, paste your script.js into jshint.com. It will flag things like: undeclared variables (a likely typo), unreachable code after a return, and loose equality (==) where you probably meant strict equality (===) — exactly the kind of collision-detection bug that's brutal to track down by playtesting alone.

Trap — Where Everyone Gets Ambushed: "No red errors in the Console" does NOT mean your code is correct — it only means nothing has crashed yet. A linter catches a whole category of bugs (typos, accidental global variables, loose equality) that run just fine but produce the wrong result, like a hitbox that "works" 90% of the time because of a subtle logic slip.
Quick Check

Why can a game run with zero errors in the Console and still have serious bugs?

Show Answer

The Console only reports errors that stop execution (crashes). Logic mistakes — like using == instead of ===, or a collision check with the wrong variable — run without crashing but produce the wrong result. A linter performs static analysis to catch these before you even hit play.

Don't confuse the browser Console (runtime errors, Chapter 9) with a Linter (static analysis, before runtime). Professionals use both.

Debugging Your Game: Breakpoints, Step Over & the Call Stack

Why it matters: Sooner or later your game will freeze, and the Console will be empty. No red error, nothing. Where do you look first? A game loop runs 60 times a second, so you need tools that can stop time and let you look around.

First suspect: when a game freezes with no error, a common cause is an infinite loop: a loop that never ends (like a while loop whose condition never becomes false), so the browser never gets the chance to draw the next frame. Put a console.log() inside the game loop to watch your values change frame by frame, or better yet, set a breakpoint.

The Three DevTools Debugging Tools
  • Breakpoint: a marker that pauses your code on a specific line so you can inspect it: exactly what every variable holds at that moment.
  • Step Over: runs the current line, then pauses again on the next one, so you can walk through your code line by line and see exactly where a value goes wrong.
  • Call Stack: the list of functions that were called to reach the paused line. It shows where the code stopped and how it got there (for example, gameLoop → checkCollisions).
How to Set a Breakpoint
  1. Open DevTools (F12, or right-click → Inspect) and click the Sources tab.
  2. Open your script.js and click the line number where you want to pause. A blue marker appears.
  3. Reload the page. Your code pauses on that line.
  4. Hover over variables to see their values, then press Step Over to run one line at a time. Check the Call Stack panel to see which function you are in.
The Three Most Common Game Bugs
  • Forgetting to call gameLoop() at the end of the script. The engine is built, but nobody turned the key, so nothing moves.
  • Forgetting this. inside a class method. The computer looks for a global variable instead, which causes a Reference Error.
  • A scope error on the canvas context. If ctx is created inside a function, your classes cannot reach it. Declare canvas and ctx at the top of script.js, before your classes use them.
Lint to Zero: a linter flags style (quality) problems as well as likely bugs. Before you turn in your game, debug it, lint it down to zero warnings, and document each fix: what was wrong and what you changed. That log is your proof of professional QA.
Pro Tip:

Breakpoint vs. Linter: a breakpoint pauses your code while it runs so you can inspect it. A linter reads your code without running it. Run the linter first to catch typos, then use breakpoints to find logic that runs wrong.

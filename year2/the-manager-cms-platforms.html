Chapter 12: The "Manager"

Content Management Systems (CMS) & Platforms

Agency Scaling: Stop Coding Everything from Scratch

You know how to code. You can build a beautiful, responsive, interactive website from a blank text document. But what if the Carson High Web Design Agency gets hired to run a news website like IGN or the Nevada Appeal? They publish 100 new articles every single day. Do you think a web developer is manually opening an index.html file, typing out <p> tags, and pushing to GitHub 100 times a day? Absolutely not.

To maximize our agency's profit margins and empower our clients to make simple updates, we use a CMS. What does CMS stand for? It stands for Content Management System. It is a "system" designed to "manage" website "content" without needing to touch the code.

This changes your job. What is the primary difference between a builder and a manager in web design? Builders code from scratch; managers use a pre-built CMS to post content quickly. As an agency developer, your job is no longer to write the articles. Your job is to set up the CMS architecture so the marketing team, writers, and business owners can log in and manage the site themselves safely.

Static vs. Dynamic: The Core Distinction

Before pitching a platform, a professional agency developer must understand the fundamental difference between how static and dynamic sites work.

Static Websites vs. Dynamic CMS-Powered Sites
FeatureStatic Website (HTML/CSS)Dynamic CMS Site (WordPress etc.)
How pages are served Pre-built HTML files sent directly to the browser. No processing. PHP queries the database, assembles the page, and sends HTML on each request.
Speed Very fast — no server processing needed. Slower (can be optimized with caching plugins).
Security Very secure — no database, no login, no attack surface. More attack surface: database, login page, plugin vulnerabilities.
Updating content Hard — must edit code files and re-deploy every change. Easy — log in to the dashboard, type, click Publish. No code.
Server requirement Any basic file host or CDN works (no PHP/database needed). Requires PHP + MySQL database on the server.
Best for Portfolio sites, landing pages, small brochure sites that rarely change. Blogs, business sites, e-commerce — anything updated frequently by a non-developer.
Cost Cheapest hosting possible (GitHub Pages = free). Requires managed hosting with PHP/MySQL support.

The Matrix: Pitching Platforms to Clients

How can you tell if a piece of software is truly a CMS? It separates the content creation from the code structure and design. This means your articles are stored in a database, and your design is stored in a Theme. If a Theme is the "clothes" of a website, what is the database? The brain/memory that remembers the content.

Because they are separate, what happens to your blog posts if you switch to a completely different WordPress Theme? The design changes, but the text and posts remain perfectly intact! Can you switch WordPress Themes without losing your Media Library uploads? Yes! The Media Library is the digital warehouse where all uploaded photos and videos are stored separately.

The 3 Tiers of Web Creation
Platform Type Examples Pros & Cons
"No-Code" Builders Wix, Squarespace Pro: What is the primary advantage of a 'No-Code' builder like Squarespace compared to a CMS? They are easier and faster for absolute beginners with no technical knowledge to set up.
Con: What is the primary disadvantage of a 'No-Code' builder like Wix? Vendor lock-in: you do not own the code and cannot easily move your site to a different hosting provider.
SaaS CMS (Rental) WordPress.com, Shopify Which platform represents the 'Rental' model where the hosting company manages everything for you? WordPress.com. You pay for convenience and hosting, but customization is limited.
Self-Hosted CMS (Owner) WordPress.org, Drupal, Joomla Which platform represents the 'Owner' model where you download free software and host it yourself? WordPress.org. Why is WordPress.org the professional standard over website builders like Wix? Because of total freedom and ownership of every line of code. Joomla is another open-source, self-hosted CMS — more flexible than WordPress for complex, multi-user sites, but with a steeper learning curve and a much smaller plugin ecosystem.
The King of the Web: WordPress powers over 40% of the entire internet. What does it mean that WordPress is 'Open-Source'? The source code is free and available for anyone to inspect, modify, and enhance. What programming language powers the logic and templates of WordPress? PHP.

Note: Which of the following is NOT a popular Content Management System? Photoshop! That is a photo editor, not a website manager!
Beyond Blogs: CMS Trends & Learning Management Systems

Not every CMS is built for the same job. Trends in how CMS platforms are used keep evolving:

  • Blogging: The original use case — reverse-chronological Posts, exactly what you're building for Local Legends Coffee.
  • Online Magazines & News: Heavy use of Categories, multiple Authors with different Roles, and high publishing frequency (think IGN or the Nevada Appeal from the start of this chapter).
  • Corporate Websites: Fewer Posts, more static Pages (About, Services, Careers) — content changes rarely, so structure and Permalinks matter more than publishing speed.

There's also a specialized category of CMS you already use every day without thinking about it: the Learning Management System (LMS). An LMS is a CMS purpose-built for education — instead of managing blog Posts, it manages courses, assignments, grades, and student submissions. Canvas (the platform your own school likely uses), Google Classroom, and Moodle are all LMS platforms.

Trap — Where Everyone Gets Ambushed: Students often don't realize Canvas is a CMS. The pattern is identical: content (assignments, announcements) is stored in a database, separate from the "theme" (your school's Canvas branding/layout) — the exact Content/Database/Theme architecture from Figure 12.2, just applied to coursework instead of blog posts.

Information Architecture & The Dashboard

How do you typically access the hidden back-end login screen of a standard WordPress site? By Adding /wp-admin to the URL. Once logged in, you enter the Dashboard. What is the WordPress 'Dashboard'? It is the private back-end mission control for the website.

Content Types: Pages vs. Posts

A professional agency developer never confuses a Page with a Post.

  • Pages: What is a WordPress 'Page'? Timeless, permanent information that doesn't expire or belong on a news feed. If you want to create a 'Contact Us' section that lives in your main menu, should you use a Post or a Page? A Page.
  • Posts: What is a WordPress 'Post'? A timely, reverse-chronological news article or blog update. If you want to announce a weekend sale that expires on Sunday, should you use a Post or a Page? A Post.

Which piece of content relies heavily on Categories and Tags for searching? Posts. Categories are for broad topics (e.g., "News", "Events"), while Tags are for specific, detailed keywords. Because there can be hundreds of posts, they need organization labels.

Categories vs. Tags — Know the Difference
FeatureCategoriesTags
Purpose Broad, hierarchical groupings — the main topic of a post. Specific, non-hierarchical keywords — details about the post.
Hierarchy Can have parent and child categories (e.g., Drinks → Espresso). Flat — no parent/child relationship.
Required? Yes — every Post must have at least one Category. Optional — use them when they add useful context.
Example Post about a pumpkin latte → Category: "Seasonal Flavors" Tags: "pumpkin," "fall," "limited edition," "espresso"
Analogy Like a book's chapter heading — broad and structural. Like a book's index entries — specific and cross-referencing.

What is the difference between a 'Draft' and a 'Published' post? Drafts are saved in the back-end but hidden from the public; Published posts are live.

Settings & Permalinks

Settings are crucial for professional decorum. When you change the 'Site Title' in WordPress General Settings, what happens? The browser tab and site header update instantly across the entire site.

What is the purpose of the 'Permalink' setting? To control the structure of the URL (e.g., making it `/about-us` instead of `/?p=123`) for better SEO and readability. You should always set Permalinks to "Post Name" before creating content!

Which setting sets a static page instead of blog posts on the front page? Settings > Reading.

Pro Tip: What does the 'Screen Options' tab do in the Dashboard? It allows you to hide or show specific panels on your admin screen to reduce clutter for clients.

Writing Content: The Block Editor

What is the modern default WordPress editor called? The Block Editor (Gutenberg), named after the inventor of the printing press. How does the Block Editor handle content? Every paragraph, image, or video is its own movable block.

Mastering the Editor
  • Adding Content: Where do you find the button to add new elements in the Block Editor? Look for The '+' Icon (the universal symbol for add/new).
  • Moving Content: What feature in the Block Editor allows you to move a paragraph above an image? The drag-and-drop handles or up/down arrows on the block.
  • Custom Code: If the Block Editor doesn't have a specific visual feature you need, how can you write code directly? Use a 'Custom HTML Block'!
  • Mistakes: If 'Manager Mike' accidentally deletes a paragraph in the Block Editor, what is the fastest way to get it back? Use the 'Undo' button (or Ctrl+Z) in the editor.
  • Revisions: If you really mess up, you can restore a backup. What is a WordPress 'Revision'? An automatically saved previous version of a post that you can restore if you make a mistake.
Featured Images & Shortcodes

Every post needs a Featured Image. What is it? The main thumbnail people see when the post is shared on social media.

You will also frequently use Shortcodes. What is a 'Shortcode'? A small piece of code in brackets (e.g., [gallery id="5"]) that executes a larger script or plugin feature within a post.

The Clothes: Themes & Child Themes

What controls the 'Look' or visual design of a WordPress site? A Theme. This dictates your global colors, typography, and layout structure. If you want to build a highly customized page layout for a client that the standard Block Editor can't handle, what type of plugin would you install? A Page Builder Plugin (like Elementor or Divi).

Widgets & Menus

Themes give you control over sidebars and footers using Widgets. What is a Widget? A small, self-contained module that adds specific functionality (a search bar, recent posts list, calendar, or social feed) and can be dragged into designated "widgetized areas" — typically sidebars and footer columns — without writing any code. Where would you typically place a copyright notice that needs to appear on every single page of the site? In the Footer widget area (via Widgets or Theme Customizer).

Navigation is handled separately. Where do you manage the layout of your site's navigation links? Appearance > Menus.

Page Builders

What is a Page Builder? A drag-and-drop visual editing tool (plugins like Elementor, Divi, or Beaver Builder) that lets you assemble complex page layouts by dragging content sections, columns, and pre-built widgets onto a live visual preview — no HTML or CSS knowledge required. When a client wants a unique homepage layout that Gutenberg's block editor can't handle, a Page Builder is the agency's power tool.

Gutenberg vs. Page Builders: Gutenberg (the default block editor) is great for standard posts and pages. Page Builders are better for pixel-precise custom landing pages. However, heavy Page Builder plugins can slow down a site, so only install one if genuinely needed.
Where This All Came From: WYSIWYG Software

Gutenberg and Page Builders like Elementor belong to a much older category of tool: WYSIWYG software, pronounced "wizzy-wig," standing for "What You See Is What You Get." A WYSIWYG editor lets you build a page visually — dragging, dropping, and formatting — while the software writes the underlying HTML/CSS for you behind the scenes, instead of you hand-typing every tag.

The classic, historical example is Adobe Dreamweaver: a desktop application (predating modern CMS platforms) that let designers lay out entire websites visually and export the generated HTML/CSS files directly, with no server or database involved at all. Today's WYSIWYG tools have largely moved inside the CMS itself — the Gutenberg Block Editor and Page Builder plugins you just learned are both modern, browser-based WYSIWYG editors.

Trap — Where Everyone Gets Ambushed: WYSIWYG tools are fast, but the HTML they auto-generate is often bloated with extra <div> tags and inline styles compared to hand-written code. A professional developer still needs to know how to read and clean up that generated markup — WYSIWYG speeds up building, it doesn't replace understanding HTML/CSS.

The Golden Rule: Child Themes

What is the primary purpose of a Child Theme? To preserve your custom code when the parent theme receives updates. Without a child theme, every time the parent theme developer releases a security patch or feature update, WordPress overwrites the theme files — and all of your custom CSS is permanently deleted. A child theme inherits 100% of the parent theme's design and functionality, but stores your customizations in a separate folder that updates never touch.

Child Theme Rule: Any time you write custom CSS or edit theme template files for a client, always do it in a child theme. The extra 10 minutes to set one up saves hours of re-coding after the inevitable theme update.

Plugins, Security, & SEO

In the 'Smartphone' analogy, what do WordPress Plugins represent? The apps you download to give the phone new powers. What is used to add new functionality (like a store or contact form) to a WordPress site? A Plugin. (For example, what is 'WooCommerce'? The most popular e-commerce plugin that turns a WordPress site into an online store!)

Integrating a Shopping Cart: WooCommerce Step-by-Step

Say Manager Mike wants to sell bags of his coffee beans online, not just advertise the shop. That means integrating a real shopping cart, not just a plugin install:

  1. Install WooCommerce: Go to Plugins > Add New, search "WooCommerce," install and activate. A setup wizard walks you through store basics (currency, location, units).
  2. Add Products: WooCommerce creates a new "Products" content type (alongside Pages and Posts). Each product gets a price, description, inventory count, and a Featured Image — just like writing a Post.
  3. Connect a Payment Gateway: WooCommerce doesn't process money itself — it hands the transaction to a Payment Gateway (Stripe or PayPal are the most common) that securely charges the customer's card and deposits funds into the client's bank account.
  4. The Cart & Checkout Pages: WooCommerce automatically generates a Cart page (where items a shopper has added are listed) and a Checkout page (where they enter shipping/payment info) — you don't hand-code these, but you can style them via your Theme.
  5. Require HTTPS: A store must run on SSL/HTTPS (Chapter 11) before going live — browsers block card entry on insecure pages, and payment processors legally require it.
Trap — Where Everyone Gets Ambushed: Installing WooCommerce and adding products isn't enough to accept real money — forgetting to configure a Payment Gateway means the checkout page exists but every purchase attempt will fail. Always test a complete purchase (using the gateway's "test mode") before launching a client's store.
The Danger of Plugin Bloat

What is the primary risk of installing too many WordPress plugins? They can slow down the site, cause conflicts, and create security vulnerabilities. This is known as "Plugin Bloat."

Furthermore, what does it mean if a plugin has not been 'tested with your current version of WordPress'? It might be abandoned by its developer and could break your site or introduce security flaws. Updating vulnerable plugins immediately demonstrates the WRS skill of Probity / Ethical Adherence.

Plugin Security Checklist — Before You Install

Before installing any plugin for a client site, run through these checks in the WordPress Plugin Directory:

  • Last Updated: Was it updated within the last 6 months? An abandoned plugin is a security time bomb — it won't be patched when WordPress releases security fixes.
  • Active Installations: Is it used by at least 1,000+ sites? Popular plugins get audited by the community. Obscure plugins with 50 installs may contain malicious code.
  • Star Rating: Does it have 4+ stars with a reasonable number of reviews? Read the 1-star reviews — they often expose critical bugs.
  • WordPress Compatibility: Does it say "Compatible with your version of WordPress"? If not, it may break your site.
  • Keep Plugins Updated: Enable automatic updates for plugins, or check for updates weekly. An out-of-date plugin is the #1 attack vector for hackers on WordPress sites.
  • Delete Unused Plugins: A deactivated plugin still exists in your files and can still be exploited. Delete any plugin you aren't actively using.
Rule of Thumb: Ask yourself — "Can I build this feature with a block in Gutenberg instead?" Every plugin you don't install is a security risk you don't have.
Security & Roles

How do you ensure a client's WordPress site remains secure from hackers? Regularly update the WordPress core, themes, and plugins to patch vulnerabilities. BUT wait! Before updating the WordPress core or installing a major plugin, what is the single most important action a professional developer must take? Perform a complete database and file Backup.

Why is it important to assign 'Roles' (like Editor, Author, Contributor) to users in a CMS? To restrict permissions so an author (like Manager Mike) can't accidentally delete the entire website or change the theme. Which user role has absolute total control over every aspect of a WordPress site? The Administrator.

SEO & Caching

How does a CMS help with SEO (Search Engine Optimization)? By automatically generating clean HTML structure, sitemaps, and allowing plugins (like Yoast) to optimize keywords.

To make your site lightning fast, use Caching plugins. What is 'Caching' in the context of a CMS? Creating static copies of dynamic pages so they load much faster for visitors.

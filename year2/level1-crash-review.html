Level 1 Crash Review

A fast recap of Chapters 1-8 before we build "The Brains" (JavaScript)

Welcome Back, Junior Developers

Before we hand you JavaScript — the language that makes your sites do things — we need to make sure everything you built in Year 1 is still solid. Nobody wires up interactivity on a shaky foundation. This page is a fast, no-fluff recap of every Chapter 1-8 concept you'll lean on constantly this year. Skim it, refresh your memory, then take the pre-test below.

Need more than a refresher on any one topic? Every heading below links back to that chapter's full lesson.

1. The Developer's World

  • You're not just a student — you're part of a professional Agency, and the industry expects Continuous Learning because tech changes fast.
  • The Internet is the physical network of connected computers; the Web is one service that runs on top of it (email and gaming are others).
  • DNS translates human-readable domain names into IP addresses. Hosting is where a site's files actually live.
  • The Web Development Life Cycle (WDLC) — plan, design, build, test, launch, maintain — keeps client projects from blowing their budget or deadline.
  • Professional file-naming rules matter: lowercase, no spaces, hyphens instead — about-us.html, not About Us.html.

2. The "Rules" (Legal & Ethics)

  • Copyright protects original creative work automatically; you can't just grab an image off Google and use it commercially.
  • Creative Commons licenses spell out exactly how a creator allows their work to be reused.
  • Accessibility (alt text, color contrast, keyboard navigation) isn't optional — the Domino's lawsuit confirmed websites are legally public accommodations.
  • An NDA protects a client's trade secrets; you'll sign versions of these in the real industry.

3. The Blueprint (Planning)

  • A Sitemap is the tree diagram of every page on a site and how they connect.
  • A Wireframe is a low-fidelity, grayscale sketch of a page's layout — content and structure only, no colors or fonts yet.
  • Planning before coding saves massive rework time later — this is true for JavaScript apps too, where you'll now plan logic, not just layout.

4. UI/UX Design

  • UX (User Experience) is how a product feels to use; UI (User Interface) is the actual visual controls the user touches.
  • Design for a specific persona — a fictional target user — instead of designing for "everyone."
  • Color theory and typography choices aren't decoration — they guide the user's eye and set the tone.
  • Avoid Dark Patterns — UI tricks designed to manipulate users into actions they didn't intend.

5. The "Bones" (HTML)

  • HTML is structure, not styling — every page needs <!DOCTYPE html>, <html>, <head>, and <body>.
  • Elements have an opening and closing tag: <p>text</p>. Void elements like <img> and <br> don't need a closing tag.
  • An attribute adds info to a tag: <img src="cat.jpg" alt="A cat">.
  • Every element JavaScript will target this year — buttons, inputs, divs — starts as plain HTML. You can't manipulate an element that isn't there.

6. The "Clothes" (CSS)

  • Selectors target which elements get styled: element (p), class (.card), or ID (#header).
  • The Box Model — content, padding, border, margin — controls every element's spacing.
  • Classes can be reused on many elements; IDs should be unique to one element per page — the same rule JavaScript relies on when you use document.getElementById().
  • Specificity determines which conflicting CSS rule wins.

7. Advanced Layout

  • Flexbox lays elements out along a single row or column and handles alignment/spacing automatically.
  • CSS Grid lays elements out in a full two-dimensional row-and-column grid.
  • Responsive Design (media queries) adapts a layout to different screen sizes — mobile, tablet, desktop.

8. Sights & Sounds

  • Image formats matter: JPG for photos, PNG for transparency, SVG for scalable icons/logos.
  • Always optimize/compress media — huge unoptimized files are one of the most common reasons real sites load slowly.
  • The <video> and <audio> tags embed native media players without needing external plugins.

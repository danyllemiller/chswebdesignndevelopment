Web Design I

Build the foundations of a professional web career — from design thinking and wireframes to HTML, CSS, and your first JavaScript-powered portfolio.

2 Semesters 8 Units CTE Pathway Up to 9 College Credits

Course Description

Semester 1 (Design First) establishes the professional mindset before a single line of code is written. Students study web history, ethics, copyright law, and career paths. They learn audience analysis, user personas, and information architecture — then wireframe and sitemap a full website before opening a code editor.

Semester 2 (Building & Launching) brings everything to life. Students master CSS layout systems (Box Model, Flexbox, Grid), responsive design, and accessibility compliance. The year concludes with a JavaScript-powered personal portfolio — the first piece of your professional career.

Course Units

Semester 1 — Design Foundations
1
The Developer's World

History of the web, W3C standards, browser evolution, and the Developer's Guild mindset.
2
The "Rules" — Web Law & Ethics

Copyright, Creative Commons, ADA compliance, privacy law, and how not to get sued.
3
The Blueprint — Planning & Design Process

ADDIE cycle, user personas, SEO basics, sitemaps, and wireframing with industry tools.
4
The "Why" — UI/UX Design

Design principles, color theory, typography, visual hierarchy, and usability testing.
Semester 2 — Building the Web
5
The "Bones" — HTML5

Semantic HTML5 structure, document flow, lists, tables, forms, and link architecture.
6
The "Clothes" — CSS3

Selectors, the Box Model, positioning, transitions, and styling a full multi-page site.
7
The "Style" — Advanced CSS Layout

Flexbox, CSS Grid, responsive breakpoints, and building mobile-first layouts.
8
Sights & Sounds — HTML Media

Embedding images, audio, video, and animation; performance optimization and ADA media requirements.

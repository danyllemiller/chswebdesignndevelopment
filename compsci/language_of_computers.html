5.1 Bits, Bytes & Binary

A computer only ever stores two things: 0 and 1. Not letters, not colors, not sound. Everything you've ever seen on a screen — this sentence included — is secretly a very long string of 0s and 1s that something else knows how to interpret.

5.1.1 Place Value in Base 2

Decimal (base 10) uses place values of 1, 10, 100, 1000. Binary (base 2) uses place values of 1, 2, 4, 8, 16, 32, 64, 128 — each one double the last.

Worked Example: Converting 01001101

128  64  32  16   8   4   2   1

  0    1   0   0   1   1   0   1

Add up the columns with a 1: 64 + 8 + 4 + 1 = 77. That's it — that's the whole trick.

Eight of these digits — a bit each — make one byte. A byte has exactly 256 possible values (2 to the 8th power), because each of its 8 bits can be either a 0 or a 1. That's not an arbitrary number — it's why an 8-bit color channel maxes out at 255, and why some old video games had a hard score limit around 65,535. The bit width sets the ceiling.

Quick Check

Convert the decimal number 20 into binary. (Answer: 10100 — that's 16 + 4.)

5.2 Hexadecimal

Binary is exact, but it's unreadable to a human — nobody wants to type out 24 digits of 0s and 1s to describe a color. Decimal doesn't map cleanly onto bytes either. Hexadecimal (base 16) exists to solve exactly this problem: it's a compression of binary designed for human eyes.

5.2.1 Why Two Hex Digits Equal One Byte

Hex uses sixteen symbols: 0 through 9, then A through F standing in for 10 through 15. Because 16 × 16 = 256 — the exact number of values in one byte — exactly two hex digits can represent any byte perfectly. That's why you'll never see a hex color code with an odd number of characters per channel.

Worked Example: Decoding #FF5733

Split it into pairs: FF 57 33. Convert each pair to decimal: FF = 255, 57 = 87, 33 = 51. That's the color's Red, Green, and Blue values — RGB(255, 87, 51), a bright orange-red.

The trap: students often think hexadecimal is a completely separate system from binary, unrelated to what they just learned. It isn't — it's literally the same data, just grouped four bits at a time and relabeled with a friendlier symbol. Nothing about the underlying value changes.

5.3 Character Encoding

A computer stores the letter A the exact same way it stores anything else: as a number. Character encoding is the agreed-upon map between numbers and the characters they represent.

5.3.1 From ASCII to Unicode

ASCII was the original standard: a 7-bit map assigning a number to every letter, digit, and basic symbol used in English. It worked — until the rest of the world needed computers too. ASCII had no room for accented letters, non-Latin alphabets like Arabic or Japanese, or emoji.

Unicode replaced it as the modern standard, with room for every writing system on Earth and far beyond ASCII's original 128 characters. Every emoji you've ever sent is a Unicode character with its own assigned number, exactly like the letter A has one.

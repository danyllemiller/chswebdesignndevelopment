Unit 4: Beg. Algorithm & Programming — Project

The Algorithm Design Blueprint

Built in Google Slides. No real code required. 100 points.

Standards Addressed

Nevada Academic Content Standards for Computer Science & Integrated Technology: 9-12.AP.A.1 (create prototypes that use algorithms to solve computational problems), 9-12.AP.C.1 (justify control structure selection), 9-12.AP.C.2 (use events to initiate instructions) — the same standards Chapter 9's labs (The Decomposition Tree, The Pseudocode Spec, The First Prototype) and Chapter 10 (The Decision Logic, The Iteration Build, The Event-Driven Artifact) build toward.

Objective

Design a complete algorithm for a real problem — decomposed, written in pseudocode, with your control-structure choices explicitly justified. This is a design document, not a coding assignment; no code editor required.

Deliverable: A Google Slides deck, minimum 6 slides. Turn in a PDF export or a text file with your share link below.

New to Google Slides? Start here: Ch 4.0, The Office Suite, From Zero »

Steps

Each step below links to the chapter section that actually teaches how to do it — do that first if you haven't already.

  1. Pick a real problem to solve (a simple game, a quiz scorer, a class-schedule picker, etc.).
  2. Decomposition Tree — a visual breakdown of the problem into its smaller subproblems. How to: Ch 9.1, Decomposition »
  3. Pseudocode — write out the full algorithm in pseudocode, not real code. How to: Ch 9.2, Algorithms & Pseudocode »
  4. Control Structure Justification — your pseudocode must include at least one decision (if/else) and one loop; explain why you chose that specific structure over an alternative. How to: Ch 10.1, Conditionals » · Ch 10.2, Loops & Iteration »
  5. Event-Driven Design — describe one real user action that would trigger your algorithm, and exactly what response follows. How to: Ch 10.3, Events That Trigger Code »
  6. Trace Walkthrough — hand-run your algorithm with 2 different sample inputs and show the output for each, step by step. How to: Ch 10.4, Lists & Systematic Testing »

Unit 3: Data & Analysis — Project

The Data Story Dashboard

Built in Google Sheets. 100 points.

Standards Addressed

Nevada Academic Content Standards for Computer Science & Integrated Technology: 9-12.DA.S.1 (translate between bit representations), 9-12.DA.S.2 (tradeoffs in how data is organized/stored), 9-12.DA.CVT.1 (interactive data visualizations), 9-12.DA.IM.1 (computational models of data relationships) — the same standards Chapter 5 (The Binary Translator, The Encoding Lab), Chapter 6 (The Organization Audit, The Storage Tradeoff Matrix), Chapter 7 (The Function Toolkit, The Chart Rebuild) and Chapter 8 (The Model Build, The Reality Check) build toward.

Objective

Build a real, multi-tab Google Sheets workbook that translates raw bits into readable data, weighs real storage tradeoffs, visualizes a dataset you actually care about, and tests a simple prediction against it.

Deliverable: A Google Sheets workbook with 4 tabs (see below). Turn in a PDF export or a text file with your share link below.

New to spreadsheets entirely — rows, columns, cells? Start here: Spreadsheet Basics, From Zero »

Steps (one tab each)

Each step below links to the chapter section that actually teaches how to do it — do that first if you haven't already.

  1. Tab “Bit Translator” — build a working reference table converting at least 8 real values across binary, hexadecimal, decimal, and ASCII/Unicode character. How to: Ch 5.5, Doing This in Google Sheets »
  2. Tab “Storage Tradeoffs” — pick a real dataset you care about (sports stats, a music library, game scores, etc.), organize it two different ways (e.g. one big flat table vs. split into related tables), and write out the real pros/cons of each — speed, size, ease of updating. How to: Ch 6.1, Organizing Data »
  3. Tab “Dashboard” — build at least 2 real charts from your dataset using actual formulas (SUM, AVERAGE, COUNTIF, etc.) — not typed-in numbers. How to: Ch 7.1–7.2, Formulas & Data Visualisation »
  4. Tab “Model & Predict” — build a simple formula-based model that predicts an outcome from your data, then write a sentence checking whether the prediction actually held up against real or plausible data. How to: Ch 8.1, Building a Model »

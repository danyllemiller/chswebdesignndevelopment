The TL;DR: What You Really Need to Know

The Core Concepts of CSS

  • CSS solves one big problem: it separates content from presentation, so one external .css file can update the look of an entire site instead of editing every tag by hand.
  • Every rule has two parts: a selector (what to style) and a declaration block — one or more property: value; pairs inside { } .
  • The most specific selector wins: ID ( #main ) > Class ( .cool-thing ) > Element ( p ) .
  • Colors can be written as Named ( tomato ), Hex ( #FF6347 ), RGB, or HSL — add an Alpha value (RGBA/HSLA) for transparency.
  • Everything is a box. Learn the Box Model (margin, border, padding) to control spacing.
  • Use rem for font sizes. It's flexible and scalable.
  • Pseudo-classes ( :hover ) style special states; pseudo-elements ( ::before ) style parts of an element or inject new content.
  • Use the W3C CSS Validator to find bugs your browser silently hides from you.

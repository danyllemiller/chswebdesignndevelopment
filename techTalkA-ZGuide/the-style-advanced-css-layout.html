Tech Talk: Chapter 7

Advanced Vocabulary for Professional Architects

Vocabulary Expansion

Box Model

The 4 layers of every HTML element, from the inside out: Content, Padding, Border, and Margin.

Breakpoint

The specific pixel width where a Media Query triggers a layout change (e.g., 768px for tablets).

clamp()

A CSS function that clamps a value between an upper and lower bound. Used for Fluid Typography to make text grow and shrink smoothly with the screen size.

Compile / Compiler

The process (and the tool) that translates a preprocessor language like Sass (.scss) into plain, browser-readable .css.

Document Flow

The default way a browser places elements on a page: top to bottom, based on each element's display type.

Flexbox

A CSS layout module (display: flex) for arranging items in a single row or column (1-dimensional layout).

fr Unit

A "Fractional Unit" used in CSS Grid that represents a fraction of the available free space in the grid container.

Media Query

An "If-Then" CSS rule (@media) that applies specific styles only when the screen matches a condition, like a minimum or maximum width.

Mixin (Sass)

A reusable "recipe" of CSS declarations in a preprocessor that you can drop into any rule, similar to a function.

Mobile-First

A design strategy where you code styles for small screens first, then use min-width media queries to add complexity for larger screens.

Nesting (Sass)

Writing a child selector visually inside its parent selector in a preprocessor, so the compiled CSS matches your HTML's structure without retyping the parent.

Partial (Sass)

A small, separate Sass file (like _buttons.scss) that gets imported and combined into one compiled stylesheet, keeping large projects organized.

Preprocessor

A scripting language (like Sass or LESS) that extends CSS with variables, nesting, math, and mixins, then compiles down into plain CSS a browser can read.

Sass / LESS

The two most common CSS preprocessors. Sass files typically use the .scss extension.

Viewport Meta Tag

The <meta name="viewport"> tag required in the <head> before any media query will work correctly on mobile devices.

CSS Variables (Custom Properties)

Entities defined by CSS authors that contain specific values to be reused throughout a document. Declared in the :root and accessed via the var() function.

minmax()

A CSS Grid function that defines a size range greater than or equal to min and less than or equal to max. Essential for preventing grid items from getting too small.

Overflow

The CSS property that controls what happens when content is too big for its box. Options include visible, hidden, scroll, and auto.

Stacking Context (z-index)

The three-dimensional conceptualization of HTML elements along an imaginary Z-axis. z-index determines which overlapping element appears "on top."

Sticky Positioning

A positioning type that toggles between relative and fixed, depending on the user's scroll position. Useful for headers that stay visible only when needed.

Test Alert!

Q: Difference between auto-fill and auto-fit?

A: auto-fill keeps empty tracks; auto-fit collapses empty tracks to stretch existing items.

Headphone Barcode Labels

Prints on plain paper (or a full-page sticker sheet): 30 boxes per page, each 4.3 cm × 2.5 cm. Cut along the black lines. Each sticker scans as HP01–HP30.

  • In the print box, set Scale: 100% / Actual size (not "Fit to page") and turn Headers and footers off, or the labels won't line up.
  • Check the size with a ruler on the first page: each box should be exactly 4.3 cm wide and 2.5 cm tall.
  • Scan one sticker on the checkout page to test before sticking them all on.

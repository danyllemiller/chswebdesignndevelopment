Lesson 4: DNS & IP Addresses

Explain20 min

  • Define DNS (Domain Name System — the phonebook).
  • Trace the lookup sequence: Browser → Resolver → Root → TLD → Authoritative Server.

Grading Rubric (3.0 Target): successfully logs 3 IP addresses and correctly orders the DNS sequence.

Lesson 8: Summative Assessment (Chapter 1 Exam)
20 questions · 35–40 min · block 8
  1. What is the mandatory filename for a homepage? index.html
  2. What does DNS do? Translates domain names to IP addresses
  3. What is the Internet? The physical hardware, cables, and routers
  4. What is the World Wide Web? The software service and HTML documents
  5. What is a CTSO? Career tech org like SkillsUSA/FBLA used for networking
  6. What does an IP address act as? The numerical GPS coordinate of a computer
  7. Why must developers avoid spaces in filenames? Servers read spaces as broken %20 characters
  8. What does the W3C do? Creates the open standards for the web
  9. Who invented the World Wide Web? Tim Berners-Lee
  10. What is the Client-Server model? The browser requests files, the server delivers them
  11. What does the “S” in HTTPS stand for? Secure / SSL Certificate
  12. What is an Intranet? A restricted, private internal network
  13. What are Soft Skills? Communication, empathy, teamwork
  14. What is Rubber Duck Debugging? Explaining code aloud to find logical errors
  15. What is a Top-Level Domain (TLD)? The .com, .org, or .edu portion of a URL
  16. What is IaaS? Infrastructure as a Service — renting raw hardware
  17. What is SaaS? Software as a Service — using a finished cloud product like Google Docs
  18. Which role focuses on writing HTML/CSS/JS? Front-End Developer
  19. What does ICANN do? Manages the global domain name system
  20. Why are lowercase filenames important? Linux servers are case-sensitive

Lesson 1: Psychology of Design (Visual Hierarchy)

Engage10 min
  • Project a modern, clean website (like Apple.com) alongside a cluttered, chaotic website from the late 90s.
  • Ask students to perform the “Squint Test”: squint their eyes until the text is blurry.
  • Discuss: “What are the first 3 things your eye is naturally drawn to on the clean site vs. the messy site? Why?”
Explore20 min
  • Provide a “Design Deck” (digital or physical blocks of different shapes and colors).
  • Challenge students to arrange the blocks to make one specific shape the “Leader” using only Size, then only Color, then only White Space.
Explain20 min
  • Define Visual Hierarchy: the deliberate arrangement of elements to imply importance.
  • Explain the core principles: Scale (bigger = more important), Contrast (difference creates focus), and Proximity (things close together are related).
  • Emphasize the importance of White Space (Negative Space) to reduce cognitive load.
Elaborate40 min

Objective: demonstrate analytical reasoning by identifying design patterns on live interfaces.

Instructions:

  1. Find a landing page for a modern app (e.g., Spotify, Discord).
  2. Take a screenshot and draw numbered arrows pointing to the top 3 elements in the Visual Hierarchy.
  3. Identify the Primary CTA (Call to Action) and circle the White Space used to make it stand out.

Turn In: submit your annotated screenshot.

  • Define Typography rules: font pairings, establishing an H1–H6 size scale, and readability.

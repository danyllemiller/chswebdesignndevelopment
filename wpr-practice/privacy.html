Privacy Policy

Effective October 23, 2026

The short version: WPR Practice Pro does not keep your information. There are no accounts, no database of students, no ads, and no tracking. While a test is in progress, the server holds the test-taker's name, student ID, and answers in temporary memory so the teacher can see results. That memory is erased when the teacher ends the session, after 12 hours, or whenever the server restarts. It is never saved to a database or file. The only thing the site saves is practice questions that teachers choose to upload, which contain no student information.

1. Who we are

WPR Practice Pro (wprpracticepro.com, "the site") is an independent practice tool that helps students prepare for the Nevada Workplace Readiness Skills assessment. Teachers give the practice test to their own classes. The site is not operated by, endorsed by, or affiliated with the Nevada Department of Education, any school district, or the official assessment's publisher.

2. What information the site uses

Students type their first name, last name, and student ID number to join a test, plus a class code from their teacher. During the test the site uses the questions they were given, the answers they choose, their score, and how many times the test screen was left (for example, switching tabs).

Teachers enter a teacher passcode and may enter their name (it only appears on the class report they download). The site creates a class code and a private access key for their session.

Question banks. Teachers may upload their own practice questions (and answers) to reuse in future tests. These are the one thing the site saves: the questions, their answer choices and answers, the bank's name, and, if the teacher types it, the uploading teacher's name. Question banks never contain student information, and they are shared with every teacher who has the teacher passcode. Teachers must not put student names or any personal information in a question.

That is everything. The site does not ask for email addresses, phone numbers, birthdates, addresses, passwords for accounts, photos, or any other information.

3. How it is used

The information is used only to run the practice test: to show each student their questions and results, and to show the teacher who gave the test their own class's progress and scores so the teacher can download them. It is never used for advertising, marketing, building profiles, or anything else, and it is never sold, rented, or shared with anyone.

4. How long it is kept

Test information exists only in the server's temporary memory while a session is open. It is never written to a database, file, or backup. It is permanently erased as soon as the first of these happens:

  • the teacher clicks End session;
  • 12 hours pass since the session started; or
  • the server restarts.

After that, the information cannot be recovered by anyone, including the site owner.

5. Downloads belong to the teacher

Teachers may download their class's results as a spreadsheet (CSV) or a printable report. Once downloaded, those files are in the teacher's control, not the site's. Teachers are responsible for storing, sharing, and deleting them according to their school's and district's student-privacy policies.

6. What is stored on your device

The site does not use cookies for tracking or advertising. To let a page be refreshed without losing a test in progress, the browser keeps a small temporary note on the device:

  • For students: the class code and a session key, plus any questions flagged for review. This is kept in the browser's session storage and disappears when the browser tab is closed.
  • For teachers: the class code and the session's private access key, kept in the browser's local storage until the teacher ends the session.

Scratch paper and calculator work stay on the screen only and are never sent anywhere.

7. Server logs and our network provider

The site's own server does not keep access logs for wprpracticepro.com. To stop people from guessing passcodes or class codes, the server briefly uses a visitor's internet (IP) address to count recent attempts. This count is kept in memory for no more than 15 minutes and is never saved.

The site is delivered through Cloudflare, a network and security provider. Like any website host or network, Cloudflare processes technical information such as IP addresses and browser type to deliver pages and protect against attacks, and may set strictly necessary security cookies. Cloudflare handles that information under its own privacy policy (cloudflare.com/privacypolicy). The site does not use Cloudflare or anyone else for analytics or advertising.

8. Students and school privacy laws

The site is intended for high school students using it at a teacher's direction and is not directed to children under 13.

Because the site keeps no student information after a session ends, it does not maintain education records. Results a teacher downloads may become part of the school's records under the Family Educational Rights and Privacy Act (FERPA) and the school's own policies. The site does not sell student information, use it for targeted advertising, or build profiles of students, consistent with Nevada's student data privacy law for school service providers (NRS 388.281 to 388.296). Teachers should follow their district's process for approving online tools before using the site with students.

9. Security

All connections to the site are encrypted (HTTPS). The correct answers are kept on the server and are not sent to a student's browser until that student submits the test. Each teacher can see only their own session, and each session is protected by a private access key.

10. Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date. Because the site keeps no information between sessions, a change can never apply to information collected before it.

11. Questions

Students should ask the teacher who gave them the test. Teachers and others can contact the site owner at contact@wprpracticepro.com.

⚠️ SQL Injection — How It Works

✅ Normal Login Attempt
User enters:
username: alice
password: mypassword
▶ SQL query built
Query sent to DB:
SELECT * FROM users
WHERE username='alice'
AND password='mypassword'
▶
Result:
✓ 1 row found
Login allowed
🚨 SQL Injection Attack
Hacker enters:
username: admin'--
password: (anything)
▶ injected SQL
Malicious query:
SELECT * FROM users
WHERE username='admin'--
AND password='xxx'
-- comments out the password check!
▶
Result:
✗ No password
needed — access
GRANTED!
🛡️ Fix: Use Prepared Statements — they separate the SQL code from the user's input so special characters like ' and -- are treated as plain text, never as commands.

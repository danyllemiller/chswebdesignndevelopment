CMS Architecture — Separating Content from Design

📝

Content Layer

Blog posts, pages, images, and media uploaded by the author. Written once — can be displayed anywhere, in any design.

⬇
🗄️

Database Layer (MySQL)

Stores all content as structured data — posts, users, comments, settings. The CMS queries this database to retrieve content on demand.

⬇
🎨

Theme / Presentation Layer

Templates and CSS that control how content looks — fonts, colors, layout. Swap the theme and the entire site redesigns instantly, with zero content changes.

⬇
🌐
Rendered Webpage (HTML sent to browser) Content + Database + Theme combine at request time to produce the final HTML page the visitor sees.
